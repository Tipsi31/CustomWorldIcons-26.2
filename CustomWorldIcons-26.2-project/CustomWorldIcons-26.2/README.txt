Custom World Icons 26.2 Fabric

IMPORTANT: This ZIP is a build project, not the finished tested mod JAR.
GitHub Actions builds it using Java 25.

Steps:
1. Create a new empty GitHub repository.
2. Upload ALL files/folders from this ZIP (including .github).
3. Open Actions -> Build 26.2 Fabric -> Run workflow.
4. Download the CustomWorldIcons-26.2 artifact.

Current source is a compile-safe 26.2 target scaffold. It does NOT yet change icon resolution; the exact 26.2 world-icon method must be patched after checking the 26.2 client signature. Do not treat a successful build as a functional high-resolution icon mod yet.
